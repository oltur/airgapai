# docs/

- **[`architecture.md`](architecture.md)**: the parts, how a question and a ticket flow through
  them, and where each rule is enforced.
- **[`threat-model.md`](threat-model.md)**: STRIDE and LLM-specific threats, each with its control,
  test and residual risk.
- **[`evidence.md`](evidence.md)**: each claim, its test, its latest run and what it does not
  prove, and what none of it shows.
- **[`adr/`](adr/)**: architecture decision records. Copy
  [`0000-template.md`](adr/0000-template.md) to add one.
- **[`hours.md`](hours.md)**: active hours per phase against the planned budgets, generated by
  `scripts/hours.py` on each commit.
